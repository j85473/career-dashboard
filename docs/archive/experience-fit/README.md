# Archived Experience Fit designs

The records in this directory describe the superseded criterion/EFEI design
discussion. They remain available as historical context but are not active
runtime or implementation authority.

Experience Fit v2 now uses two plain-text Terra calls: a Medium hard-requirement
gate and, for survivors, a High holistic 0-100 Expertise Fit score. Deterministic
code harvests the essential output, creates the upload JSON, and the Dashboard
applies the 70-point lifecycle threshold.
