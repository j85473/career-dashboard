# Historical Experience Fit v1

These schema-bound criterion prompts are retained only for replaying historical
`career-dashboard-experience-export-v1` artifacts. The active Experience Fit v2
runner does not load them.

Active v2 uses one Terra Medium hard-requirement gate followed, when clear, by
one Terra High holistic Expertise Fit score. There are no criterion extraction,
coverage-audit, evidence-binding, weighting, or model-repair phases in v2.
