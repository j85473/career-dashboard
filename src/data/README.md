# Offline search geography

`usSearchCities.json` contains US city centers, generated by
`node scripts/build_search_city_data.mjs` from the pinned development dependency
[all-the-cities](https://github.com/zeke/all-the-cities) (MIT license).
The underlying data is from [GeoNames](https://www.geonames.org/), licensed under
[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
Each row is `[city, state abbreviation, latitude, longitude]`.

The runtime also uses the BSD-licensed [zipcodes](https://github.com/davglass/zipcodes)
package for US ZIP centers and smaller postal cities. Distances are approximate
straight-line distances between these centers, rather than driving distances.
These lookups are used only for search; they do not alter saved jobs or scoring.
